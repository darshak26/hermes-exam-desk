# Official starting points per exam family

Portals **rotate yearly** (the GATE and JAM organizing institute changes every year; NTA exam sites move). These are STARTING POINTS for `web_search`, not addresses to trust blindly — always locate the current year's official information bulletin before citing a pattern number. GAT-B/BET details below were current for the 2026 cycle.

| Exam family | Who conducts it | Starting points to search |
|---|---|---|
| **Anything NOT listed here** | the exam's own conducting body | locate it with `web_search` first ("<exam> <year> information brochure official"), then proceed with the SAME procedure — the table is a shortcut for common families, not a gate |
| JEE Main, CUET, UGC NET, GPAT, CMAT and other NTA exams | NTA | `nta.ac.in`; per-exam portals like `jeemain.nta.ac.in` |
| GAT-B / BET | NTA for Regional Centre for Biotechnology (DBT) | `dbt.nta.ac.in`; RCB's DBT-PG portal `rcb.res.in/DBTPG` |
| GATE (all papers incl. BT) | A rotating IIT | `gate.iitg.ac.in` / the organizing IIT's GATE page for that year; official question papers + answer keys are published on the GATE portal |
| IIT JAM (incl. BT) | A rotating IIT | the organizing IIT's JAM portal for that year; official papers + keys on the JAM portal |
| DBT-PG admissions (context) | RCB | `rcb.res.in` |

## Provenance labels (mandatory — never mix silently)

Priority order, strongest first:

1. **Official paper + official key** — `provenance: "official paper + official key"`.
2. **Official paper + reputable coaching key** — `provenance: "official paper; answer key cross-checked against <site>"`.
3. **Memory-based reconstruction** — `provenance: "memory-based reconstruction by <source>; unverified"`. Memory-based questions regularly carry wrong keys and missing options; the label is the protection.

Every question carries its own `source_url` (the page or PDF the question came from). Pack-level `source_url` is the paper's origin.
